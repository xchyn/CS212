Key Idea— what this page is

This is the same set of lecture notes the students get, with one difference: every class is linked here, whether or not it has been posted to them yet. The student index releases classes one at a time as the semester goes on; this page does not.

Read as far ahead as you like. It is the fastest way to see exactly what the lecture said, in what order, and with what wording, so lab can build on it rather than guess at it.

Warning— please don't forward the unposted ones

Classes are released to students on or just after the day they are taught. If a page reaches a student early, the predict-first exercises stop working for them — they will have read the answers before the lecture asks the question.

So: use these to prepare, and point students at the student index rather than sending files on. If a student needs a page that is not up yet, ask the instructor to release it.

1.How the pages work

Two mechanics are worth knowing before you open one in front of a lab.

Procedure— the toggles
  1. Every worked example hides its output and explanation behind a green toggle, and every Quick Check and Practice Problem hides its solution behind a grey one. Nothing shows an answer until it is clicked.
  2. Show all and Hide all at the top of each page open or close every toggle at once. Hide all turns the page into a problem set; Show all turns it into a worked solution set.
  3. Printing follows the toggles: whatever is closed on screen is left out of the printout. So printing with everything hidden gives you a clean lab worksheet, and printing after Show all gives you the answer key.
  4. The orange boxes are live-coding areas. Tab indents, Reset restores the starter code, Copy puts it on the clipboard. They do not compile or run anything — there is no compiler in a browser. In print they come out as empty ruled boxes, which makes them usable as "write your answer here" space.

Everything is a single self-contained file. No internet, no install, no shared drive needed — a folder on a USB stick works, and so does opening one file straight from an email attachment.

Every program on these pages was compiled with javac and run; the output blocks are what it actually printed, not what it ought to print, and the compiler messages are real javac output. The commands taught to students are the plain two, javac Prog.java then java Prog, so lab and lecture agree.

3.Background reading

There is one page outside the 28 classes:

CSCI 111 Refresher — variables and arithmetic, decisions, loops, methods, arrays, String and Scanner. It is the CSCI 111 material this course assumes students already have, rewritten in Java rather than the language they first met it in, and it is available to students from day one — so you can point anyone at it immediately.

It deliberately stops short of anything the course teaches itself. If a student is stuck on classes and objects, references, or ArrayList, send them to the class rather than the refresher. The one part worth flagging early is the nextInt()-then-nextLine() trap, which the refresher covers and which catches somebody in every lab in the first fortnight.
